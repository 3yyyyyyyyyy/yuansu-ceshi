# yuansu-ceshi
# 原神元素反应伤害计算测试脚本

## 项目简介
本项目是一个基于 Python `unittest` 框架的自动化测试脚本，用于校验《原神》中**蒸发**和**融化**两种元素反应的伤害计算逻辑是否正确。

## 为什么要做这个项目？
- 我在准备游戏测试岗位面试时，发现“游戏数值校验”是测试工程师的核心能力之一
- 元素反应是原神战斗系统的灵魂，涉及多个乘区（攻击力、倍率、元素精通、怪物抗性等），非常适合作为测试练习场景
- 本项目模拟了真实测试工作中“输入参数 → 校验输出 → 报告结果”的完整闭环

## 覆盖的测试类型
| 测试类型 | 说明 | 用例数量 |
|---------|------|---------|
| 功能测试 | 验证蒸发/融化在不同触发顺序下的伤害倍率是否准确 | 4 |
| 边界值测试 | 验证元素精通为 0 和 1000 时的伤害计算 | 2 |
| 异常测试 | 验证传入错误参数时是否正确抛出异常 | 2 |
| 数据驱动测试 | 多组攻击力参数下批量校验计算结果 | 1（内含4组数据） |

**共计 9 个测试用例，全部通过 ✅**

## 运行方式
```bash
python test.py
```
